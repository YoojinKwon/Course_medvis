2️⃣ GITHUB에 올리지 않은 파일 ❌ (MIMIC 규정 위반)
================================================================================

이 파일들은 PhysioNet 규정상 공개할 수 없습니다.
사용자가 PhysioNet에서 직접 다운로드해야 합니다.

❌ backend/prepared_v5/ (2.6GB) - MIMIC 의료 데이터 기반
   - windows.npy (2.4GB): 신호 데이터
   - shap_3d.npy (152MB): SHAP 값
   - metadata_v2.csv (16MB): 환자 메타데이터
   - linear_classifier.pkl (148KB): 학습된 모델
   - linear_faiss.bin (33MB): FAISS 인덱스
   - allowed_subjects.json (<1KB): 환자 목록
   - channels.json: 채널 정의 (설정이므로 포함 필요)

❌ database/ (1.9GB) - 의료 데이터베이스
   - waveform30.db: 환자 임상 기록

4️⃣ 사용자 가이드
================================================================================

MIMIC 데이터를 사용하려는 사용자는 다음 단계를 따르세요:

1. PhysioNet 계정 생성
   https://physionet.org

2. MIMIC-IV 데이터 다운로드
   https://physionet.org/content/mimic-iv/

3. 디렉토리 구조 설정
   prepared_v5/
   ├── channels.json
   ├── metadata_v2.csv
   ├── linear_classifier.pkl
   ├── linear_faiss.bin
   ├── windows.npy
   ├── shap_3d.npy
   └── allowed_subjects.json

   database/
   └── waveform30.db

4. 환경변수 설정
   export PREPARED_DIR=/path/to/prepared_v5
   export NOTES_DB=/path/to/database/waveform30.db
   export ML_PORT=5003

5. 서비스 실행
   pip install -r requirements.txt
   python backend/ml_service/app.py
